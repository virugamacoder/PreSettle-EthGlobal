# backend

The Pre Settle API: Node 20 + Express 5 + viem + the Arkiv SDK. **No database**: the order book is on Arkiv and the money is on Arc.

Live at **https://3.109.65.92.nip.io** (API under `/v1`, health check at `/health`).

What it does:
- **Verified order book:** reads OTC listings from Arkiv and checks each one against the Arc escrow (the Arkiv owner must be the on-chain maker, and the order must still be open). Fake or stale listings are dropped.
- **Keeper:** every 30 seconds it records each order's deadline from Arkiv and, once the deadline passes, calls the permissionless `expire()` on Arc so the maker is refunded.
- **Analytics:** open orders, premarket offers, fills, 24 h volume, trending tokens and active makers, computed from Arkiv.
- **Prices:** USD reference prices from CoinMarketCap.
- **Admin:** Sign-In with Ethereum sessions and logo uploads.

## Run locally

```bash
cd backend
cp .env.example .env     # missing values just switch features off
npm install
npm run dev              # http://localhost:3000
npm test                 # 28 tests
```

On startup the server logs which features are **on** and which are **off** because of missing configuration.

## API

| Method | Path | Auth | Description |
|---|---|---|---|
| GET | `/health` | — | `{"status":"ok"}`; used by Docker, nginx and the deploy workflow |
| GET | `/v1/config` | — | Public settings: chain ID, USDC/EURC, contract addresses, feature flags |
| GET | `/v1/status` | — | Latest block on Arc / Arkiv / Sepolia, platform account, keeper status |
| GET | `/v1/orders` | — | OTC orders from Arkiv, verified on Arc. Query: `side`, `offerToken`, `wantToken`, `maker`, `partial`, `minPrice`, `maxPrice`, `limit` (≤100), `cursor` |
| GET | `/v1/analytics` | — | Market stats computed from Arkiv (cached 60 s) |
| POST | `/v1/views/:key` | — | Count a view of a listing (once per visitor per 10 min) |
| GET | `/v1/views?keys=` | — | View counts for up to 100 listings |
| GET | `/v1/prices?ids=` | — | USD prices by CoinMarketCap ID (cached 5 min) |
| GET | `/v1/auth/nonce` | — | One-time nonce for Sign-In with Ethereum |
| POST | `/v1/auth/verify` | — | `{message, signature}` → session token (admins are wallets in `ADMIN_WALLETS`) |
| POST | `/v1/admin/uploads` | admin | PNG/JPEG/WebP/GIF body (≤512 KB) → `{url}` |
| GET | `/uploads/:file` | — | Uploaded logos |

Admin routes need `Authorization: Bearer <token>` from `/v1/auth/verify`. The broker endpoints (`/v1/brokers`, `/v1/admin/brokers`) exist but are off (feature paused).

## Code layout

| Path | What's inside |
|---|---|
| `src/app.js` | Express app: security headers, CORS, routes, error handling |
| `src/config.js` | Validated environment (zod) and feature flags |
| `src/chains.js` | Arc, Arkiv and Sepolia clients, platform wallet |
| `src/services/` | Orders (Arkiv query + Arc verification), analytics, prices, views |
| `src/routes/` | One file per API area |
| `src/keeper.js` | Automatic expiry of past-deadline orders |
| `src/auth.js` | Sign-In with Ethereum sessions |
| `src/arkiv/schemas.js` | Arkiv schemas (same as the frontend's) |
| `src/contracts/` | OTC contract reads; `abi/` is **generated by `npx hardhat compile`** in `contracts/` |
| `scripts/arkiv-query.js` | Read-only query of the live order book (for judges) |
| `test/` | node:test suites |

## Configuration

See [.env.example](.env.example); every variable is documented there. In production the **whole file** is stored in **one** GitHub secret, `BACKEND_ENV_FILE` ([docs/DEPLOYMENT.md](../docs/DEPLOYMENT.md)).

| Feature | Needs |
|---|---|
| Order verification on Arc | `OTC_CONTRACT` |
| Arkiv (higher rate limits) | `ARKIV_ACCESS_KEY` |
| Admin sign-in | `AUTH_SECRET`, `ADMIN_WALLETS`, `SIWE_DOMAIN` |
| Keeper | `KEEPER_ENABLED=true`, `PLATFORM_PRIVATE_KEY` (testnet-only wallet with Arc USDC for gas), `OTC_CONTRACT` |
| Reference prices | `COINMARKETCAP_API_KEY` |
| View counts, uploads | `DATA_DIR` (a Docker volume on the server) |

## Deployment

The Docker image is built from this folder; `docker-compose.yml` + `nginx/nginx.conf` run it on AWS EC2 behind nginx with a Let's Encrypt certificate. GitHub Actions deploys on every push to `main` that changes `backend/`, or by hand from **Actions → Deploy Backend → Run workflow**. Full guide: [docs/DEPLOYMENT.md](../docs/DEPLOYMENT.md).
