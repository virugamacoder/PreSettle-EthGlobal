# frontend

The Pre Settle web app: React 19 + Vite + Tailwind CSS + wagmi + viem + RainbowKit + TanStack Query + the Arkiv SDK.

Live at **https://presettle-ethglobal.vercel.app**.

## Run locally

```bash
cd frontend
cp .env.example .env      # VITE_BASE_URL defaults to http://localhost:3000/v1
npm install
npm run dev               # http://localhost:5173
npm run build             # production build in dist/
```

## Chains

The app switches the wallet automatically; users only approve MetaMask's prompts.

| Chain | Used for | Gas |
|---|---|---|
| **Arc Testnet** (5042002) | Money: approve, lock, fill, buy, deliver, claim, reclaim, cancel, withdraw, admin contract actions | USDC |
| **Arkiv Rabdi** (7794095) | Data: publish a listing, record a fill or purchase, remove a listing, token list, profiles | tGLM |
| **Sepolia** | ENS: shows a maker's name instead of their address | — |

## Pages

| Route | What it does |
|---|---|
| `/` | **Premarket**: token banners, live offers from Arkiv, market stats, search |
| `/premarket/:key` | Offer details; buy before TGE (shows the minimum first purchase); deliver, claim default, cancel, reclaim unsold |
| `/otc` | **OTC** order book (Arkiv listings verified on Arc by the backend), filters: side, token, max price, partial fills |
| `/otc/:key` | Order details; fill (partial or full) or cancel |
| `/create` | Create an OTC order or a premarket offer (`?tab=premarket`, `?side=buy`) |
| `/dashboard` | My orders, my premarket offers, my fills, **Balances** (withdraw from both escrows) |
| `/admin` | Sign-In with Ethereum; platform fees, premarket markets (create, logo, pause, move TGE, set real token), token list |
| `/settings` | Theme and the Arkiv trader profile |

`/broker` and `/deal/:key` exist in the code but are hidden from the menu (feature paused).

## How a transaction flow works

Every write is shown as a numbered **step list** with explorer links, for example *Approve → Lock in escrow (Arc) → Publish listing (Arkiv)*.

- **Network switching:** `src/lib/chain.js` (`switchAndWait`) waits until the wallet itself reports the new chain before sending, which avoids MetaMask chain-mismatch errors.
- **Arkiv writes** use the user's own wallet (`src/arkiv/wallet.js`), so the user owns the entity. If the Arc part succeeded but the Arkiv write failed, the step list offers **Retry the Arkiv step**, so the user never pays twice.
- **Errors** from the contracts are shown in plain words (`src/components/TxSteps.jsx`).
- **Admin transactions** are simulated first, so a call that would revert costs no gas.

## Code layout

| Folder | What's inside |
|---|---|
| `src/pages/` | One file per route |
| `src/components/` | Header, order lists, step list, token banners, forms, configuration check |
| `src/hooks/` | Data hooks: orders, premarket, tokens, my activity, views, admin session, theme |
| `src/arkiv/` | Arkiv client (reads with the access key), wallet client (writes), schemas |
| `src/contracts/` | Contract helpers; `abi/` holds the ABIs **generated by `npx hardhat compile`** in `contracts/` |
| `src/lib/` | API client, number/format helpers, chain switching, OTC create flow |
| `src/config/` | Environment settings and the wagmi/RainbowKit config |

## Environment

See [.env.example](.env.example). **Everything here is public** (built into the browser bundle); never put a private key in it. After changing a variable on Vercel, **redeploy**.

| Variable | Notes |
|---|---|
| `VITE_BASE_URL` | Backend API including `/v1` |
| `VITE_WALLETCONNECT_PROJECT_ID` | From cloud.reown.com; needed for mobile/QR wallets |
| `VITE_ARC_TESTNET_RPC_URL` | Defaults to `https://rpc.testnet.arc.io` |
| `VITE_OTC_CONTRACT_ARC_TESTNET`, `VITE_PREMARKET_CONTRACT_ARC_TESTNET` | Contract addresses; must match the backend |
| `VITE_ARKIV_ACCESS_KEY` | Arkiv Hub key; add the site to its **Origins** |
| `VITE_ARKIV_ADMIN_ADDRESS` | Wallet that publishes the token list; must match the backend |
| `VITE_SEPOLIA_RPC_URL`, `VITE_ENS_PARENT_NAME` | ENS on Sepolia |

## Deploy

Vercel with **Root Directory = `frontend`**; every push to `main` redeploys. See [docs/DEPLOYMENT.md](../docs/DEPLOYMENT.md).
