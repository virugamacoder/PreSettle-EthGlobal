# contracts

Solidity contracts for SettleX on **Arc Testnet** (chain 5042002).

They are written, tested and deployed in **Arc Studio** (https://studio.arc.io), then pulled here with `arc-studio pull`.
The Arc Studio prompt is in [docs/PLAN.md](../docs/PLAN.md) §6.6.
